Magic commands are Jean's opinionated shortcuts for common development moves.

They package prompt construction, git actions, and context loading into workflows that are easier to repeat than a hand-written prompt every time.

## What lives in the magic menu

Jean groups magic commands into a few main areas.

## Context

- **Save Context** stores a summarized snapshot for later reuse
- **Load Context** pulls a saved summary back into the current flow
- **Linked Projects** shares context across related repositories (see [Project linking](/core-concepts/project-linking))
- **Create Recap** generates a digest of the current session

## Commit and sync

- **Commit**
- **Commit & Push**
- **Revert Commit** reverts the last local commit after confirmation
- **Pull**
- **Push**

These work well when you want Jean to help with the commit message or guide the sequence instead of manually stitching it together.

## Pull request work

- **Open or Create PR**
- **Update PR** refreshes the title and description on an existing PR using current commits
- **Review** runs an AI code review and stores findings you can revisit in the Review panel
- **PR Comments** loads inline review comments so Jean can address them one by one
- **Merge**

Jean can generate PR content, review diffs, and help address inline review comments from an existing PR.

Open or Create PR and Update PR both use the Generate PR Content prompt, so you can tune voice, structure, and required fields once and reuse them everywhere. See [Magic prompts](/manage/magic-prompts).

## Investigation and release work

- **Investigate Issues**
- **Investigate Pull Requests**
- **Generate Release Notes**

These flows are useful because Jean already knows how to load and format the surrounding context before the model starts reasoning. Generate Release Notes compares against a selected GitHub release, inspects matched merged PRs, and carries detected closing issue references into the generated notes.

## Branch work

- **Merge**
- **Resolve Conflicts**

The conflict workflow is especially useful when you want Jean to stay with the operation until the repo is back in a healthy state.

## Why these are different from plain prompts

Magic commands carry defaults for:
- prompt templates
- model choice
- provider choice
- backend choice
- reasoning effort

You can override those defaults in the [Magic prompts pane](/manage/magic-prompts), which means the workflow stays the same while the engine behind it changes.

## Opening the magic menu

- `Cmd+M` on macOS or `Ctrl+M` elsewhere opens the menu from any chat
- each item has a single-letter shortcut once the menu is open (for example, `K` for Linked Projects)

## Good uses for magic commands

Use a magic command when:
- the task is common and repeatable
- you want Jean to pull structured context first
- the output format matters
- you want the same flow across many repos

Use a plain chat message when:
- the task is unusual
- you are still exploring the problem
- you want a looser conversation before choosing a workflow
