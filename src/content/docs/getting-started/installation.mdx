## Install dependencies

```bash
cd src
bun install
```

## Start the docs app

```bash
bun run dev
```

The docs app runs on `http://localhost:3000/docs`.

## Content locations

- App code lives in `src/src`
- Documentation content lives in `src/content/docs`
- Static assets for the docs path live in `src/public/docs`
- Build-time generators live in `src/scripts`
