Welcome to the Jean docs workspace.

This starter is already wired for static export, local search, build-time OG images, sitemap and robots generation, Plausible analytics, and nginx deployment.

<Callout title="Good to know">
All of the examples below work on this site without importing components at the top of each MDX page.
</Callout>

## Authoring notes

- Markdown images are zoomable by default.
- Fumadocs UI components are available in MDX without page-level imports.
- Search uses the local static index generated from your content.
- The deployable static output ends up in `src/.output/public`.
